# Участие в разработке UniStore

Спасибо за интерес к проекту. Здесь описано, как сообщать об ошибках, предлагать функции и присылать изменения.

## Перед началом

- Прочитайте [README.md](README.md) и [FAQ](README.md#faq).
- Проверьте, нет ли уже похожего issue или pull request.
- Для вопросов и обсуждений используйте [Discussions](https://github.com/NetlApps/UniStore/discussions).
- Для уязвимостей используйте [SECURITY.md](SECURITY.md), а не публичный issue.

## Сообщение об ошибке

Создайте issue через форму «Сообщение об ошибке» и укажите:

- версию UniStore, Android и прошивки;
- модель устройства;
- магазин или источник;
- пакет и версию приложения, если проблема связана с обновлением;
- шаги воспроизведения, ожидаемое и фактическое поведение;
- `logcat` с тегом `UpdateHub`, если есть.

Перед отправкой удалите из логов и скриншотов токены, почту, IMEI, номера телефонов, имена аккаунтов и другие личные данные. Не прикладывайте APK, если у вас нет прав на его распространение.

## Предложение функции

Создайте issue через форму «Предложение функции». Опишите проблему, которую нужно решить, и только потом — конкретное решение. Если функция затрагивает новый магазин, приложите пример страницы и объясните, есть ли у магазина публичный API версий.

## Pull request

1. Сделайте fork и создайте ветку от `main`.
2. Внесите изменения небольшими логическими коммитами.
3. Запустите тесты и lint:

   ```bash
   ./gradlew :app:testDebugUnitTest :app:lintDebug
   ```

4. Откройте pull request и заполните шаблон.
5. Будьте готовы обсудить замечания и обновить ветку.

### Требования к коду

- Kotlin и Jetpack Compose, стиль проекта и официальный `kotlin.code.style=official`.
- Новые строки интерфейса — на русском, в `strings.xml`, если это принято в соответствующем экране.
- Новая логика должна иметь unit-тесты. Для парсеров магазинов добавьте тест на реальном фрагменте ответа без персональных данных.
- Не добавляйте рекламные и аналитические SDK.
- Не коммитьте `local.properties`, `keystore/`, `tools/`, `dl/`, `research/` и скачанные APK. В репозитории остаётся только релизный `UniStore-1.1.8.apk`.

### Сборка

Проект использует JDK 17, Android SDK 35 и Gradle Wrapper.

```bash
./gradlew :app:assembleDebug
```

Release-подпись настраивается в `local.properties` или переменных окружения `RELEASE_STORE_FILE`, `RELEASE_STORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`. Без них `assembleRelease` собирает неподписанный APK.

## Стиль общения

- Пишите по существу и уважительно.
- Критикуйте код и решения, а не людей.
- Не публикуйте чужие персональные данные.
- Сообщения на русском или английском одинаково допустимы.
