# AGENTS.md

## Релизы

- Никогда не создавай и не публикуй новый тег, GitHub Release или APK-ассет без явного подтверждения пользователя в текущем диалоге.
- Не меняй `versionCode`/`versionName` и не пушь релизный коммит без такого подтверждения.
- Описание релиза: 3–5 коротких пользовательских пунктов сверху. Технические детали, метрики, хеши и подпись — внутри `<details><summary>Подробности</summary> ... </details>`.
- Не выдумывай метрики и не публикуй непроверенные цифры.
- Правка описания уже опубликованного релиза допустима только по явной просьбе пользователя.
